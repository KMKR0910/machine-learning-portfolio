# Diabetes Prediction Model

##  Overview
This project is a machine learning model that predicts whether a person is diabetic or not using medical data.

##  Algorithm Used
- Support Vector Machine (SVM)

##  Dataset
- Diabetes Prediction\dataset\diabetes.csv
- Dataset source:https://www.dropbox.com/scl/fi/0uiujtei423te1q4kvrny/diabetes.csv?rlkey=20xvytca6xbio4vsowi2hdj8e&e=1&dl=0
- 768 samples, 8 features

##  Workflow
- Data loading
- Data preprocessing (Standardization)
- Train/test split
- Model training using SVM
- Prediction on test data

##  Output
- Classifies a person as diabetic (1) or non-diabetic (0)

## 🛠 Technologies Used
Python, Pandas, NumPy, Scikit-learn
